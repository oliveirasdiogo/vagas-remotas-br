# Contribuindo

Contribuições são bem-vindas.

1. Crie um fork e uma branch curta.
2. Não inclua credenciais, cookies ou dados pessoais.
3. Novas fontes devem usar páginas ou APIs públicas permitidas pela plataforma.
4. Adicione o domínio ao mapa de permissões somente após revisar sua legitimidade.
5. Execute `npm run collect`, `npm run check` e `npm run build`.
6. Abra um pull request explicando a fonte, os campos utilizados e os termos aplicáveis.

Coletores que contornem autenticação, CAPTCHA, rate limit ou bloqueio automatizado não serão aceitos.
